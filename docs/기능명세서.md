# 기능명세서

기획 팀이 노션에 정리한 기능명세서를 옮긴 문서예요. 우선순위는 상·중·하이고, 비어 있는 칸은 원본에서도 비어 있어요.

### 0-1. 회원가입/로그인

#### 회원가입

- 내용 없음 (원본 비어 있음)

#### 로그인

- 내용 없음 (원본 비어 있음)

## 1. 정보수집

### 1-1. 정보 불러오기

#### 클립보드 기반 링크 호출

- **설명:** 클립보드에 저장된 링크를 자동으로 불러와 입력할 수 있도록 한다.
- **언제:** 클립보드에서 불러올까요? → 네 선택 시
- **우선순위:** 상

#### 링크 붙여넣기/직접 입력

- **설명:** 모아둔 링크를 붙여넣거나 직접 입력할 수 있도록 한다.
- **언제:**
  - 1) 클립보드에서 불러올까요? → 아니요 선택 시
  - 2) 정보추출 실패 → 재시도 선택 시
- **우선순위:** 상

#### 정보 추출

- **설명:** 링크에 담긴 정보에서 요약카드로 생성할 항목들을 추출한다.
- **언제:** 링크첨부 후 확인 버튼 클릭시
- **처리:**
  - *기획_요약카드 포맷 항목 추출
  - 요약카드 항목 ([노션](https://app.notion.com/p/40619e478617800daaefcbc40bf438aa?pvs=21))
  - 추가) 교통/팁 요약 카드 항목 ([노션](https://app.notion.com/p/40619e478617802f9389dc1b53187d91?pvs=21))
- **예외:** 교통/팁 요약카드는 지도위의 노드로 배치되지 않는다.
- **우선순위:** 상

#### 정보추출 실패

- **설명:** 정보 추출 실패화면을 표시하고 재시도와 직접 입력 선택지를 제공한다.
- **언제:** 정보 추출 실패 시
- **우선순위:** 중

## 2. AI 요약카드

### 2-1. 요약카드 생성

#### 요약카드 생성

- **설명:** 추출된 항목들을 기반으로 카테고리별 카드로 완성한다.
- **언제:** 정보 추출 완료 시
- **예외:** 일부만 추출 시 → 빈 항목을 표시하고 생성
- **우선순위:** 상

#### 요약카드 직접 생성

- **설명:** 항목란을 사용자가 직접 채울 수 있도록 한다
- **언제:** 정보 추출 실패 → 직접 입력 선택 시
- **우선순위:** 중

#### 요약카드 수정 버튼

- **설명:** 생성된 카드의 항목을 확인하고 사용자가 직접 편집할 수 있다.
- **언제:** 수정버튼 클릭 시
- **우선순위:** 중

#### 요약카드 저장

- **설명:** 확인이 끝난 요약카드를 저장한다
- **언제:** 저장 클릭 시
- **처리:** 요약카드를 카테고리에 맞는 보관함에 저장한다.
- **예외:** 한번에 여러장이 생성된 경우 모든 카드를 한꺼번에 저장한다.
- **우선순위:** 상

## 3. 카테고리 보관

### 3-1. 카테고리 보관함

#### 카테고리 필터

- **설명:** 카테고리 보관함에서 원하는 카테고리를 선택하면 지도위에서 노드형식으로 볼 수 있다.
- **언제:** 카테고리 보관함 이동 → 필터 선택 시
- **우선순위:** 상

#### 카테고리별 카드 추가 버튼

- **설명:** 자신이 원하는 카테고리안에 직접 요약 카드를 추가로 생성할 수 있다.
- **언제:** 추가(+)버튼 클릭 시
- **우선순위:** 중

#### 카드 확인

- **설명:** 지도위에 노드를 클릭하면 해당 노드의 요약카드를 볼 수 있다.
- **우선순위:** 상

## 4. 여행계획

### 4-1. 여행계획 생성

#### 여행계획 생성 버튼

- **설명:** 여행 계획을 생성을 눌러 여행명, 기간, 장소를 입력해 여행계획을 만든다.
- **언제:** 여행계획 생성 클릭 시
- **처리:**
  - 여행 기간에 맞춰 일자를 생성
  - (1일차~n일차)
  - 여행장소에 해당하는 노드 불러오기
  - ai 여행계획 만들기와 직접 만들기 버튼이 나타난다.
- **예외:**
  - 입력 항목이 비면 완료 버튼 비활성화
  - 종료일이 시작일보다 앞이면 에러메세지 → “여행 기간을 다시 확인해주세요”
- **우선순위:** 상

### 4-2. AI 초안 생성

#### AI 여행계획 만들기 버튼

- **설명:** AI가 여행계획의 초안을 생성한다.
- **언제:** 여행계획 생성 후 ai초안 생성 클릭 시
- **우선순위:** 하

### 4-3. 여행계획 편집

#### 숙소 선택(출발지 선택)

- **설명:** 하루를 시작할 노드를 선택한다.
- **언제:** 직접 만들기 선택 시
- **처리:** 일차별 첫 출발지와 최종 도착지를 숙소노드로 배치한다.
- **예외:**
  - 숙소노드를 2개 이상 넣는 경우 → 숙소노드를 임의로 배치하지 않고 일자별 여행노드를 구성할 때 추가할 수 있는 노드로 함께 보낸다.
  - 숙소가 없는 경우 → 직접추가 혹은 건너뛰기 제공
- **우선순위:** 상

#### 일자 선택

- **설명:** 계획하고 싶은 일자를 선택한다.
- **언제:**
  - 숙소 선택 완료 시
  - 다음일자 선택 시
- **우선순위:** 상

#### 여행 구역 선택

- **설명:** 선택한 일자에 둘러보려고 하는 구역을 선택한다.
- **언제:** 일자 선택 시
- **처리:** 선택한 구역에 해당하는 요약카드 노드만 표시
- **예외:**
  - 구역에 해당하는 노드가 없는 경우 →  다른 구역 선택 or 직접 추가 안내
  - 교통/팁 요약카드 → 구역에 따라 필터링 되지 않고 적용지역에 해당하면 표시한다(하단에 꿀팁보기 등으로 카드를 둘러볼 수 있게)
- **우선순위:** 상

#### 카테고리 필터

- **설명:** 추가하고 싶은 카테고리를 선택할 수 있다.
- **언제:** 화면 상단 필터 조정 시
- **처리:** 선택한 구역에 해당하는 노드 중 해당 카테고리에 해당하는 노드가 표시
- **우선순위:** 상

#### 여행 노드 선택

- **설명:** 노드를 클릭하면 요약카드를 확인할 수 있고 추가하고 싶은 여행 노드를 하나씩 확정하며 계획에 추가한다.
- **언제:** 노드 클릭 후 계획 추가 버튼 클릭 시
- **처리:**
  - 노드 클릭 시 카드 확인
  - 먼저 확정한 노드 순으로 동선을 배치한다.
  - a선택 후 b선택 시 ab 순서변경
  - a선택 후 새로운 노드 선택 시 해당 노드 변경
- **예외:** 이전에 확정된 노드의 색상은 회색으로 표시 → 다음 일자에 추가할 수 있음(n일자에 추가된 일정이에요 추가할까요? 표시)
- **우선순위:** 상

#### 플랜B 지정

- **설명:** 현재 선택한 노드를 가지 못할 경우 가고 싶은 노드를 선택할 수 있다.
- **언제:** 확정한 여행 노드 → 플랜 b 추가 클릭 시
- **처리:** 플랜 b선택 시 다른색의 동선이 앞 노드에서 분기되어 나타나고 다음 노드에서 합쳐짐
- **우선순위:** 중

#### 일자 완성

- **설명:** 현재 일자의 노드를 배치한 후 완성을 누르면 다음 일자의 계획으로 넘어간다.
- **언제:** 일자 완성 클릭 시
- **처리:** 남은 일자가 있으면 다음일자로 넘어가고, 마지막 일자인 경우 계획 완성 보기로 이동한다.
- **우선순위:** 상

### 4-4. 여행계획 확인

#### 계획 완성 보기

- **설명:**
  - 상단에서 일자를 클릭해가며 완성된 계획을 확인할 수 있다.
  - 메인 동선이 나타난다.
- **언제:**
  - 마지막 일자 완성 시
  - AI초안 생성 완료 시
- **처리:**
  - 선택한 일자의 메인동선을 기준으로 계획을 지도위에 표시한다.
  - 플랜b 같이보기(옵션선택)
- **우선순위:** 상

#### 계획 수정

- **설명:** 완성된 계획을 다시 편집한다.
- **언제:** 계획 완성보기 → 수정 버튼 클릭 시
- **처리:**
  - 여행 계획 편집화면 → 여행 일자 클릭 후 여행노드 선택방식처럼 편집 가능
  - a선택 후 b선택 시 ab 순서변경
  - a선택 후 새로운 노드 선택 시 해당 노드 변경
  - 여행 일자를 꾹 눌러 일정 순서 변경 가능(3일차 ↔ 5일차)
- **우선순위:** 상

#### 계획 초대/공유

- **설명:** 완성된 계획을 함께하는 사람에게 공유할 수 있다.
- **언제:** 계획 완성보기 → 공유 버튼 클릭 시
- **처리:** 링크로 제공 → 접속하면 같은 페이지 확인
- **우선순위:** 하

## 5. 예외 상황 처리

기획 팀이 정리한 예외 상황이에요. 안내 문구는 모달(`ConfirmModal`)로 띄우고, 네/아니요는 모달의 두 버튼이에요.

### 5-1. 링크 수집

#### 중복된 링크 붙여넣기

- **언제:** 이전에 수집한 적 있는 링크를 붙여넣었을 때
- **안내:** “이전에 수집한 적 있는 링크예요. 다시 수집할까요?”
- **네:** 요약카드 생성을 시도한다.
- **아니요:** 링크 붙여넣기 화면으로 돌아간다.

#### 여러 링크 동시 수집

- **언제:** 링크를 여러 개 한 번에 넣었을 때
- **처리:** 링크마다 따로 처리하고, 결과도 링크별로 저장한다.

### 5-2. 요약카드 저장·생성

#### 보관함에 이미 있는 장소

- **언제:** 새로 만든 카드의 장소가 보관함에 이미 있을 때
- **안내:** “이전에 존재하는 노드가 있어요. 새로운 카드로 수정할까요?”
- **네:** 새로 만든 카드로 이전 요약카드를 대체한다.
- **아니요:** 새로 만든 카드를 지운다.

#### 모든 항목 추출 실패

- **처리:** 비어 있는 항목은 ‘-’로 표시한다.

#### 삭제한 요약카드 다시 만들기

- **처리:** 이전 데이터가 없는 것으로 보고 새 카드를 정상적으로 만든다.

### 5-3. 계획 생성

#### 일차별 노드 선택 건너뛰기 (카드 0개 선택)

- **처리:** 날짜만 있는 빈 일차를 만든다. 이 여행계획은 다른 일차가 완성됐더라도 **작성 중인 계획**에 보관한다.

#### 같은 기간에 새 여행계획 만들기

- **언제:** 선택한 기간 안에 다른 계획이 이미 있을 때
- **안내:** “선택한 기간 내에 다른 계획이 존재해요. 계획을 생성하시겠어요?”
- **네:** 새 계획을 만든다.
- **아니요:** 새 여행계획 만들기를 끝낸다.

#### 계획에 넣은 카드를 삭제한 경우

- **언제:** 카드를 삭제한 뒤 그 카드가 들어 있는 여행계획에 다시 들어왔을 때
- **안내:** “삭제된 장소가 있어요. 노드를 삭제할까요?”
- **네:** 해당 노드를 빼고 동선을 다시 잇는다.
- **아니요, 복구할래요:** 해당 카드를 복구한다.

### 5-4. 계획 편집

#### 기간 변경

- **기간을 줄일 때:** “남기고 싶은 일정을 선택해 주세요”를 띄우고 남길 일차를 고르게 한다.
- **기간을 늘릴 때:** 늘어난 날짜는 빈 일정으로 추가하고, 계획은 작성 중인 계획으로 옮긴다.
