# 서버 상태 관리 메모

서버에서 받아오는 데이터는 TanStack Query로 관리해요. 2026-11-17(#47)부터 모든 화면이 실제 BE API를 써요. 가짜 응답(`VITE_USE_FAKE_API`, `*.fake.ts`)은 없앴어요.

## 구조

| 파일 | 하는 일 |
| --- | --- |
| [client.ts](../src/shared/api/client.ts) | 모든 요청의 시작점이에요. 기본 주소·토큰·재발급·JSON 처리를 맡고, 실패하면 항상 `ApiError { status, code, message }`를 던져요. 파일 올리기는 `apiUpload` |
| [viewStatus.ts](../src/shared/api/viewStatus.ts) | 쿼리 상태를 `loading`·`error`·`empty`·`success` 하나로 바꿔요 |
| [queryClient.ts](../src/app/providers/queryClient.ts) | 공통 설정이에요. 4xx는 재시도하지 않고, 창을 다시 볼 때 새로 불러오지 않아요 |
| `features/*/api/*.ts` | 엔드포인트 함수와 쿼리 키를 둬요. **BE 형식과 화면 형식을 여기서 서로 바꿔요** |
| `features/*/model/use*.ts` | 화면에서 쓰는 훅이에요 |

## BE 형식 ↔ 화면 형식

화면 안쪽 타입(`Place`, `Plan`)은 그대로 두고 api 파일에서만 바꿔요. BE 명세는 [api-spec.md](https://github.com/Reeltrip/Backend/blob/main/docs/api-spec.md)예요.

| 화면 | BE | 바꾸는 곳 |
| --- | --- | --- |
| `Place.id`, `category: 'food'`, `location`, `summary`, `tag` | `placeId`, `category: 'FOOD'`, `latitude`·`longitude`, `accessText`·`openingHours`, `priceText` | [places.ts](../src/features/place/api/places.ts)의 `toPlace`, `updatePlace` |
| `Plan.title`, `destination`, `accommodationPlaceId`, `days[].zone`, `nodes[].planB` | `name`, `city`, `stays`, `days[].areas`, `nodes[].alternatives` | [plans.ts](../src/features/plan/api/plans.ts)의 `toPlan` |
| 계획 전체를 한 번에 저장 (`useUpdatePlan`) | 기본 정보 `PATCH`, 숙소 `PUT /stays`, 구역 `PUT /days/{n}/areas`, 일자 `PUT /days/{n}` | [plans.ts](../src/features/plan/api/plans.ts)의 `updatePlan`. 서버 값과 비교해 바뀐 부분만 보내요 |

## 서버 규칙 때문에 화면에서 알아 둘 것

- 장소 카드는 사진·주소·좌표가 있어야 저장돼요. 분석 결과 중 좌표를 못 찾은 카드는 서버가 빼고 저장해요(`skipped`).
- 같은 카드는 한 계획에 한 번만 넣을 수 있어요. 다른 일차에 또 넣으면 서버가 `DUPLICATE_PLAN_PLACE`로 거절하고, 화면은 저장 전으로 되돌린 뒤 안내를 띄워요.
- 플랜B는 대신할 노드와 같은 카테고리만 넣을 수 있어요(`INVALID_PLAN_PLACE`).
- 카드를 지우면 서버가 그 카드를 쓰던 계획에서도 빼요. 휴지통에서 복구해도 계획 자리는 돌아오지 않아요.
- 서버에 없어서 뺀 흐름: 중복 링크 안내, 보관함에 이미 있는 장소 안내, 같은 기간 계획 안내.
- 일본은 Google 경로 API가 대중교통을 주지 않아 택시·도보로만 나와요.

## 환경 변수

- `VITE_API_BASE_URL`: 비워 두면 운영 BE로 요청해요. 로컬 BE를 볼 때만 `.env`에 넣어요.
- `VITE_GOOGLE_MAPS_API_KEY`, `VITE_GOOGLE_MAPS_MAP_ID`: 지도. 없으면 지도 자리에 안내가 나와요.
